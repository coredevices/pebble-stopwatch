# pebble-stopwatch
Simple pebble stopwatch built to be published by Pebble in the store.

This stopwatch is very simple. Use the "select" button to play and pause it, and while it is running, click "down"
to save a lap. There can be up to twenty laps, which scroll away off the bottom of the screen. When the stopwatch
is paused, you can use the "up" and "down" buttons to scroll through the list of laps. To reset the stopwatch, simply
press "up" while it is running.
